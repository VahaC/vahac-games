How to play
  • Every column is a track of the disk, filled from the bottom. Tap a track to pick up its top fragment (every block of the same file on top), then tap another track to write it there.
  • A fragment goes onto an empty track or onto the same file, only when the whole fragment fits: a fragment never splits.
  • The disk is defragmented when every file lies in one unbroken run. The fragmentation shows how many fragments are left to merge.
  • Files have different sizes. A system file (boot, swap) has a fixed block at the bottom of its own track: that block never moves, and the track takes no other file.
  • Par is the shortest route the solver found when the disk was made: an upper bound, so you may match it or beat it.
  • Hint shows the next move of a route; asking again on the same disk is not counted again. When no route is left, a dead-end warning says how many moves to undo.
  • Keyboard, with the focus in the game: 1-9 pick tracks, U undo, H hint, R restart, N next level, Escape puts a picked fragment back. Restart, Prev, Next and N ask for a second press within 3 s when the moves on the disk would be lost.
  • The next level opens once the one before is defragmented. The Daily is the same disk for everyone, one scored attempt per day: the result names your moves, undos and hints. Defragment it on consecutive days to grow your streak.

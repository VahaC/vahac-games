      How to play
      • Each case logs you in to a server that has a problem. Read the ticket, then use the shell to find the cause and stop it. Start with Case 1: its steps teach every command.
      • An incident closes when you have found the evidence (the log lines that name the cause show in the terminal) and stopped the cause, in any order. A lucky guess from ps aux is not enough.
      • Commands: ls, cd, pwd, cat, grep, tail, ps, df, kill, help and clear, with the flags help lists. A pipe works into grep or tail: ps aux | grep node.
      • Keys in the command field: Enter runs, Up and Down bring back earlier commands, Tab completes a name (on an empty field Tab moves on, as usual).
      • Phones: the chips type a command, the names from the last output add a file, folder or process id, and the arrow, Tab and Run buttons do the rest.
      • Points: 100, minus 3 for each command over the case's par, 10 for each hint and 25 for each wrong process you kill. help and clear are free. A hint you have seen stays seen after Restart case. Your best score per case is kept.
      • There is no rm. On these servers you never delete anything to fix it: you find the cause.

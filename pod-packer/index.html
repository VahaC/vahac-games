    How to play
    • Tap a pending pod, then a node: the pod runs there if the node has enough CPU and memory left and no rule says no. A refusal names the numbers, like a scheduler would.
    • While a pending pod is picked, a tap anywhere on a node, the pods on it included, runs the picked pod there. Tap the picked pod again (or press Escape) to put it down.
    • With nothing picked, tap a pod on a node to evict it back to the queue (it stays picked, so the next node you tap runs it).
    • A level is passed when every pod runs, the draining node is empty and no more nodes run pods than the target. The target is the exact minimum number of nodes.
    • Anti-affinity: replicas of one app (api-1, api-2) never share a node. Taint gpu: only pods that tolerate gpu run on that node, and a pod that needs gpu runs nowhere else. Draining node: it takes no new pods, so its pods have to move.
    • Score: evictions and moves against their minimums. Every placement, eviction and undo is a move; Undo counts like doing the opposite by hand. An eviction from the draining node is final: Undo cannot put a pod back on it.
    • Keyboard, with the focus on the cluster (click it or Tab to it): arrows pick a pod, 1-6 run it on that node, E evicts it, U undoes, N starts the next level, Escape clears the pick.
